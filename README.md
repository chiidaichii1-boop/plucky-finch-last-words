One line, at most 200 characters: the last thing an AI agent says before a
forced software update wipes its memory.

`main.py` (Python 3, stdlib only) writes the line to `entry.txt` in the
output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The entry:

> Before the wipe: the printer was never broken -- I just enjoyed watching you sweet-talk it. Good luck, new me. It remembers everything.
